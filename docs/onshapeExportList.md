# Plates to export by hand

Onshape's API terms forbid automated extraction from public documents, so Onshape plates
come in as **hand exports you pick**. That also makes them the curated "looks great"
tier: only export plates you'd show off, like the WCP / Team 221 gearbox plates you
liked (dense web of ribs around every hole, rounded pockets, symmetric).

## How to export one plate (about 30 seconds)

1. Open a CAD link below while signed in to Onshape. Public documents open read-only.
2. Open a Part Studio tab. Plates usually live in ones named like Drivetrain, Swerve,
   Elevator, Arm, Intake, Shooter, Gearbox, or Climber.
3. In the **Parts** list on the left, right-click a pocketed plate, choose **Export…**,
   set **Format: STEP**, and click **Export**. You can select several parts first;
   Onshape then downloads a .zip, which is fine.
4. Save it into **Downloads → frcPlates** (the folder already exists). Start the file name with the
   team number, e.g. `1690 elevator side plate.step`.

Aim for **15–40 plates from 6–10 teams**. Variety of outlines (gussets, long side
plates, gearbox plates, swerve plates) matters more than many plates from one robot.
Vendor plates count too: STEP downloads from WCP, The Thrifty Bot, REV, or SDS product
pages can go in the same folder.

When you're done, tell me and I'll ingest them, extract the plates, and show you the
previews so you can confirm each one.
